Anil Thanki

 

I’m a Senior Bioinformatician at EMBL-EBI focused on building open, reproducible tools and visualisations for large-scale sequencing data. Previously, I was a Postdoctoral Research Scientist and Scientific Programmer at the Earlham Institutea>. I hold a PhD in Bioinformatics (University of East Anglia - UEA, UK), an MSc (University of Leicester, UK), and a BSc (Saurashtra University, India). Interests: open science, Galaxy workflows, and interactive data visualisation with D3.js.

Software Gallery

Open-source bioinformatics tools and visualisations I've developed for genomic data analysis and exploration.

TGAC Browser

An open-source genome browser designed for non-model organisms. Provides a flexible platform for visualising genomic features, annotations, and experimental data tracks with support for custom data sources.

View Source Manuscript

Aequatus

An open-source homology browser for visualising gene synteny and homology relationships across multiple genomes. Provides interactive visualisations of gene structures, protein domains, and comparative genomics data.

View Source Manuscript

GeneSeqToFamily

An open-source Galaxy workflow based on the Ensembl GeneTrees pipeline. Facilitates the identification of gene families, creating gene trees and visualizations using the Galaxy platform.

View Source Toolshed Repository Documentation Manuscript

WigExplorer

A BioJS component for interactive visualisation of wiggle (WIG) format genomic data. Enables exploration of continuous-valued data tracks such as ChIP-seq, RNA-seq, and other sequencing experiments.

View Source Manuscript
